## Architecture Decisions

- Configured Tailwind CSS v4 using CSS custom properties in `globals.css` mapped to design tokens via `@theme inline` matching `context/ui-context.md`.
- shadcn/ui configured with `base-nova` style and `@base-ui/react` primitives.
- Dark theme enforced across `:root` and `.dark` with no default light styling.
- Editor chrome components (`EditorNavbar`, `ProjectSidebar`, `EditorDialog`) organized under `components/editor/` adhering to the dark design tokens and floating panel radius (`rounded-2xl` for sidebars, `rounded-3xl` for modals).
- Clerk configured with `@clerk/ui/themes` `dark` base theme and custom CSS variable overrides so all Clerk components adhere to Ghost AI's palette without hardcoded values.
- Route protection enforced at project root using `proxy.ts` (Next.js 16 convention) with `clerkMiddleware` and `createRouteMatcher` for public routes defined via standard Clerk environment variables.
- Configured Prisma 7 schema using multi-file modular layout under `prisma/` with `prisma/schema.prisma` declaring the PostgreSQL datasource and `prisma-client-js` generator, and `prisma/models/project.prisma` declaring the domain models and enums.
- Prisma client instantiated via `lib/prisma.ts` as a cached singleton with global dev-mode memoization, supporting dynamic connection routing (Prisma Accelerate for `prisma+postgres://` URLs and `@prisma/adapter-pg` driver adapter for standard PostgreSQL URLs).
- Project REST endpoints isolated to backend under `app/api/projects` without touching or wiring client components. `proxy.ts` allows `/api` paths through to route handlers where Clerk `auth()` explicitly enforces `401 Unauthorized` responses instead of 307 browser redirects.
- Access control logic factored into `lib/project-auth.ts` (`verifyProjectOwner`), verifying resource existence (404) and checking ownership against Clerk's authenticated `userId` (403) before permitting mutation operations.
- Project and Liveblocks room IDs are aligned into a single persistent identifier on creation (`${slug}-${suffix}`), serving as `Project.id` in PostgreSQL and URL segment `/editor/[roomId]`.
- Server-side data fetching helper `lib/projects.ts` encapsulates Prisma queries for owned and shared projects, decoupling database schema details from client UI contracts.
- Editor home (`app/editor/page.tsx`) and project workspace (`app/editor/[roomId]/page.tsx`) are React Server Components that fetch project data during SSR/RSC streaming, eliminating initial load client fetch waterfalls.
- Project workspace route is standardized as `/editor/[roomId]`, utilizing `lib/project-access.ts` server helpers (`getClerkIdentity` and `checkProjectAccess`) to enforce ownership/collaboration checks before render and rendering `<AccessDenied />` for missing or unauthorized access.
